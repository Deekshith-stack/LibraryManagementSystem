# Final Deployment Structure

This project is prepared for static deployment using GitHub Pages.

## Project structure

```text
LibraryManagementSystem/
├── .github/
│   └── workflows/
│       └── deploy.yml
├── public/
│   ├── favicon.svg
│   └── 404.html
├── src/
│   ├── assets/
│   ├── components/
│   ├── context/
│   ├── utils/
│   ├── App.jsx
│   ├── App.css
│   ├── index.css
│   └── main.jsx
├── .gitignore
├── eslint.config.js
├── index.html
├── package.json
├── vite.config.js
├── README.md
├── DEPLOYMENT.md
├── dist/                  # production build output generated by Vite
├── node_modules/          # dependency installation folder
└── package-lock.json
```

## Deployment flow

1. Push changes to the `main` branch.
2. GitHub Actions runs the workflow in `.github/workflows/deploy.yml`.
3. Dependencies are installed with `npm ci`.
4. The app is built with `npm run build`.
5. The `dist` folder is published to GitHub Pages.

## Commands

```bash
npm install
npm run dev
npm run build
npm run preview
npm run deploy
```

## Notes

- The `base` path in `vite.config.js` is set for GitHub Pages hosting.
- The deployment artifact is the generated `dist` folder.
- Ensure the repository is set to use GitHub Pages in the repository settings.
