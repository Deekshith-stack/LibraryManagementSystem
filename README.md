# 📚 Library Management System (LMS)

A modern, responsive, and feature-rich Library Management System built with **React**, **Vite**, and **Lucide Icons**.

## 🌐 Live Demo
👉 **[Live Application](https://deekshith-stack.github.io/LMS/)**

---

## ✨ Features

- 🎓 **Student Portal**:
  - Browse available books with search & category filters
  - Borrow books & view due dates
  - Track fines and payment history
  - Request book reservations

- 📖 **Librarian Portal**:
  - Manage book catalog (Add, Edit, Remove copies, Track ISBN/Shelf location)
  - Issue & return operations with instant status updates
  - Manage and approve reservation queues

- ⚙️ **Admin Portal**:
  - System metrics & analytics dashboard
  - User management (Student, Librarian, Admin role controls)
  - Configurable loan rules, fine rates, and system preferences

- 🎨 **Modern Design**:
  - Glassmorphic UI aesthetics with dark/light harmony
  - Responsive layouts optimized for desktop and mobile

## 🚀 Quick Start

### Prerequisites
- Node.js (v18 or higher)
- npm

### Installation
```bash
# Clone the repository
git clone https://github.com/Deekshith-stack/LMS.git

# Navigate into project directory
cd LMS

# Install dependencies
npm install

# Run development server
npm run dev
```

### Production Build
```bash
npm run build
npm run preview
```

### Deploy to GitHub Pages
```bash
npm run deploy
```
